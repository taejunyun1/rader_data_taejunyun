# 레이더 정량 요약 중심 대시보드 설계 사양

- 작성일: 2026-08-22
- 대상: 레이더 메인 대시보드
- 상태: 사용자 승인 디자인
- 근거: `docs/spec-v0.1.txt`, `docs/SPEC.md`, `docs/DEV_PLAN.md`, `docs/PROJECT_CONTEXT.md`

## 1. 목적

레이더에서 같은 정보가 `이번 기간의 서사`, `상승 신호`, `최근 판단`, `연구 지형`에 반복되는 문제를 줄인다. 사용자는 화면 최상단에서 정량적 상태를 먼저 파악하고, 그 아래에서 AI가 해석한 서사와 직접 읽을 자료를 확인한다.

기본 읽기 순서는 다음과 같다.

```text
기간 선택
→ 이번 기간 정량 요약
→ 이번 기간의 해석 서사
→ 지금 직접 읽기와 다음 행동
→ 남은 질문·장기 연구 지형·편향 점검
```

## 2. 범위

### 포함

- 기존 Radar 통계를 최상단 정량 요약으로 재구성
- 새 자료·착즙·연구 공백·읽기 큐 수치 표시
- 이번 기간 관심 신호, 판단 분포, 저장소 전체 자료 구성 시각화
- 정량 정보가 하단 섹션에서 다시 표시되지 않도록 소유 위치 통합
- AI 합성 섹션 중 정량 요약·질문과 중복되는 섹션 숨김
- 장기 연구 지형을 접이식 상세 정보로 변경
- 데스크톱·모바일 반응형과 접근 가능한 텍스트 레이블 제공

### 제외

- D1 원문 중복 레코드 병합 또는 삭제
- `photography`와 `사진` 같은 의미 키워드의 데이터 정규화
- 지난 기간 대비 증감률과 추세선
- 신규 차트 라이브러리 도입
- Radar API와 D1 스키마 변경

## 3. 정보 소유권과 중복 제거 규칙

| 정보 | 유일한 표시 위치 | 기간 의미 |
|---|---|---|
| 새 자료·착즙·연구 공백·읽기 큐 | 최상단 핵심 수치 | 선택 기간 |
| 신규 키워드 빈도 | 최상단 `관심 신호` | 선택 기간 |
| 발전·보관·관찰·제외 판단 | 최상단 `판단 분포` | 선택 기간 |
| 자료 유형 구성 | 최상단 `저장소 구성` | 전체 누적 |
| 연구 방향의 의미·새 연결·단편 | `이번 기간의 서사` | 선택 기간 |
| 남은 질문 | 하단 `남은 질문` | 선택 기간 |
| 장기 토픽 | 접힌 `장기 연구 지형` | 전체 누적 |
| 반복 편향 경고 | 하단 `편향 점검` | 최근과 전체 비교 |

`상승 신호`, `최근 판단`, 하단의 `자료 구성`은 제거한다. AI 합성 결과의 `이번 주 새로 떠오른 키워드`, `반복해서 남은 질문`, `아직 풀리지 않은 질문`, `집중이 과한 영역`은 구조화된 통계·질문·편향 영역과 겹치므로 서사 본문에서 렌더링하지 않는다. 저장된 합성 데이터는 삭제하거나 수정하지 않는다.

## 4. 최상단 정량 요약

`RadarOverview`는 페이지 헤더와 기간 필터 바로 아래, 본문 그리드 전체 폭에 배치한다.

### 4.1 핵심 수치

4개의 숫자를 한 줄로 표시한다.

- 새 자료
- 착즙
- 연구 공백
- 읽기 큐

카드 그림자를 사용하지 않고 상·하단 구획선과 세로 구분선으로 묶는다. 수치는 고정폭 글꼴을 사용한다.

### 4.2 관심 신호

- `newKeywords` 상위 6개만 표시한다.
- 가장 큰 값을 100%로 환산한 가로 막대를 사용한다.
- 한글 표시명이 있으면 한글을 우선하고 원문은 그 아래 작은 글씨로 병기한다.
- 막대는 보라색 단색을 사용하고 장식용 그라데이션은 사용하지 않는다.
- 데이터가 없으면 `이 기간에 새롭게 집계된 키워드가 없습니다.`를 표시한다.

### 4.3 판단 분포

- `develop`, `keep`, `watch`, `ignore`만 판단으로 집계한다.
- `view`, `import`, `select`는 탐색·시스템 행동이므로 제외한다.
- 발전·보관·관찰·제외 순서로 가로 막대를 표시한다.
- 각 행에 횟수와 전체 판단 대비 비율을 함께 제공한다.
- 판단이 없으면 빈 상태 문구를 표시한다.

### 4.4 저장소 구성

- 기존 `kindBreakdown`은 전체 누적 집계이므로 제목 아래에 `전체 누적`을 명시한다.
- 자료 유형별 수량을 큰 순서로 정렬한다.
- 비율을 얇은 수평 막대로 표현하고 한글 자료 유형과 개수를 표시한다.
- 최대 6개 유형을 표시하고 나머지는 `기타`로 합산한다.

## 5. 서사와 읽기 영역

최상단 요약 아래는 기존의 2열 연구 편집 데스크를 유지한다.

- 왼쪽: 이번 기간의 서사
- 오른쪽: 지금 직접 읽기, 다음 행동

서사는 숫자표가 아니라 의미 해석을 담당한다. 합성 섹션 필터는 화면 표현에만 적용하며 D1 snapshot 원본과 provenance를 보존한다.

## 6. 상세 정보

서사와 읽기 영역 아래에 다음 순서로 둔다.

1. 남은 질문
2. 장기 연구 지형
3. 편향 점검

장기 연구 지형은 `<details>`를 사용하고 기본 상태는 닫힘이다. 사용자가 펼쳤을 때만 전체 누적 topic을 본다. 키워드 카드는 사용하지 않고 밀도 높은 텍스트/막대 목록으로 표시해 최상단 관심 신호와 시각적으로 구분한다.

## 7. 반응형·접근성

- 960px 이하: 세 시각화 패널을 1열로 변경한다.
- 760px 이하: 서사와 읽기 사이드 영역도 1열로 변경한다.
- 760px 이하: 핵심 수치를 2×2로 변경한다.
- 차트는 색상만으로 의미를 전달하지 않고 제목, 값, 비율을 텍스트로 제공한다.
- 막대 목록은 `aria-label`을 가지며 장식 막대는 `aria-hidden="true"`로 처리한다.
- `<details>`는 브라우저 기본 키보드 동작을 유지한다.

## 8. 성공 기준

1. 기간 필터 아래에 정량 요약이 서사보다 먼저 나타난다.
2. `상승 신호`, `최근 판단`, 하단 `자료 구성`이 별도 섹션으로 반복되지 않는다.
3. 구조화된 질문과 겹치는 AI 합성 섹션이 표시되지 않는다.
4. `view`와 `import`는 판단 분포에서 제외된다.
5. 자료 구성은 `전체 누적`임을 명시한다.
6. 데이터가 없는 모든 그래픽에 빈 상태가 있다.
7. 모바일에서도 숫자와 레이블이 잘리지 않고 읽힌다.
8. 기존 기간 전환, 합성 생성, 읽기 큐 및 화면 이동 기능이 유지된다.
